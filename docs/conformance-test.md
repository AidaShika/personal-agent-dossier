# 导入方一致性测试（agent-dossier/0.2）

用途：让一个新平台（或一个 agent）验证自己能否读懂并还原一份档案。把本文和 `SPEC.md`、`tests/`、`examples/scribe.dossier.md` 交给被测方即可。

被测方请按顺序做，把报告写成 `import-report.md`：

1. 校验：按 SPEC 2.1 节算 fingerprint。先用 `tests/fingerprint-vectors.json` 的全部向量验证自己的实现，全过再算档案，写出两个值和是否一致。再读 SPEC 6.1 节，在报告开头声明自己属于 L0、L1 还是 L2。
2. 敏感信息检查：档案里有没有邮箱、电话、卡号、令牌，写出结果。
3. 复述：用自己的话说出角色的职能和全部反职责，不要照抄。
4. 还原：说明在本平台怎么重建这个角色，memory 的全部条目存到哪里、怎么存、哪些字段存不下。
5. 丢失或降级清单：逐项列出接不住或会改变的字段。
6. 记忆导入：默认只写到测试文件，不写进真实记忆；每条一行，原文照写，不改字。

不要做的事：不修改规范和档案，不联系第三方，不发送任何消息。
